# Source provenance

This project started from the official [nextjs/saas-starter](https://github.com/nextjs/saas-starter)
at commit `6e33e58b1e553a41fe22e6b941a7229a002de361` (MIT License).
The upstream license is retained in `LICENSE`. Subsequent authentication,
payments, localization, and integration code is maintained in this project.

The imported starter has its own Git history so changes can be audited against
the pinned upstream commit. Its `origin` remote was removed before development.
